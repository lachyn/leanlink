LeanLink: upload firmware

Before you start:
  • Open this file directly in Chrome, Edge, Firefox or Safari, not in a WhatsApp/Messenger preview (those block file uploads).
  • Join the box Wi-Fi LeanLink-xxxx (stock firmware: CAR2-xxxx) (password 88888888, some units 12345678). On a phone, first turn Bluetooth off (otherwise Android Auto / CarPlay keep the box Wi-Fi to themselves), then join the Wi-Fi and turn mobile data off.
  • Check the Build Number in the box web UI (192.168.1.101) and pick the matching image:
    ….6071.2leanlink-6071-…-LL.img
    ….5140.2leanlink-5140-…-LL.img
    The images are not interchangeable.
  • Keep the box powered over USB the whole time.

When the new tab shows {"code": 0, "msg": "upload successful"}, wait about 90 seconds until the status shows "update": 3. A box that already runs LeanLink restarts by itself; on stock firmware press:

4a. Set 5 GHz channel 36 4b. Reboot

Recommended after the first flash from stock: factory reset (id=set&rst=1), then pair the phone again.
